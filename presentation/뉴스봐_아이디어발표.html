01 · 문제 정의

"상식을 늘리고 싶은데, 뉴스를 안 보게 된다"

관심 분야는 있지만 전문가는 아니고, 대화에서 뒤처지고 싶지 않은 대학생 — 바로 제 이야기입니다.

P1 · 중요도 ★★★

재미가 없다

관심 없는 기사가 먼저 보인다. "과학", "컴퓨터"로 분야를 정해도 범위가 너무 넓다.

P2 · 중요도 ★★★

내용이 부실하고 흩어져 있다

기사 하나로는 내용이 적거나 결론이 없다. 전체 그림을 보려면 여러 기사를 찾아 다녀야 한다.

P3 · 중요도 ★★

깊이 들어가면 너무 어렵다

더 찾아보면 내 수준보다 지나치게 전문적인 글이 나온다.

P4 · 중요도 ★★★

찾아보는 행동 자체를 안 한다

검색하면 해결되지만, 귀찮아서 결국 안 하게 된다.

02 · 핵심 통찰

"찾으러 가는" 구조로는 실패한다

문제와 데이터를 합치면, 해결의 방향은 두 가지로 좁혀집니다.

방향 ①

뉴스가 먼저 찾아와야 한다

찾아가지 않는 사람(P4)에게는 검색창이 아니라 알림이 필요하다.

첫 문장이 재미있어야 한다

재미없으면(P1) 누르지 않는다. 눌렀을 때는 충분하고 쉬운 정보(P2·P3)가 있어야 한다.

03 · 해결책 — 첫 버전(MVP) 범위

기능은 딱 4개만 — 작게 만들어 끝까지 동작시킨다

MVP(최소 기능 제품): 가설을 확인할 수 있는 가장 작은 첫 버전

FR-01
🎯

맞춤 기사 모으기

오늘의 화제 / 나의 관심 분야 / 추천 뉴스 3개 페이지. 큰 분야 10개 중 단계별 선택

해결: P1 재미없음

FR-02
📚

종합 기사

여러 기사를 AI가 새로 정리. 출처 링크 + 어려운 단어 탭 해설

해결: P2 흩어짐 · P3 어려움

FR-03
🎣

어그로 한 줄

규칙(강한 단어·친근한 말투) + 예시 제목 10~20개로 AI가 생성. 안내 문구 표시

해결: P1 재미없음

FR-04
🔔

알림

안드로이드 알림, 하루 3번 (7·12·19시). 누르면 해당 종합 기사로 이동

해결: P4 찾아보지 않음

4개 기능만으로 알림 → 클릭 → 종합 기사 → 출처의 한 흐름이 완성된다 — 가설을 확인하기에 충분한 최소 범위.
